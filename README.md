# CarVoice — голосовой ассистент для Android-бокса (Carlinkit)

Нажали кнопку → сказали команду → Claude понял → бокс выполнил и ответил голосом.

## Что умеет (MVP)
- **Звук:** «громче», «тише», «звук на 40», «выключи звук»
- **Музыка:** «включи Спотифай», «включи что-нибудь бодрое», «следующий трек», «пауза», «продолжи»
- **Навигация:** «поехали в Мегу Химки» (Яндекс Навигатор → Яндекс Карты → Google Maps)
- **Приложения:** «открой Телеграм», «открой YouTube и включи голосовой поиск»
- **Поиск:** «найди в ютубе обзор CLS 2019»
- **Система:** «домой», «назад»
- **Вопросы:** «сколько будет 15% от 3200», «расскажи анекдот»
- Несколько команд сразу: «включи музыку и сделай погромче»

## Установка
1. В браузере бокса откройте страницу **Releases** этого репозитория и скачайте `CarVoice.apk`
   (или скачайте на телефон и перенесите на флешку).
2. Установите APK (разрешите установку из неизвестных источников).
3. Откройте **CarVoice** (иконка с шестерёнкой):
   - вставьте API-ключ Claude (console.anthropic.com → API Keys) → **Сохранить**;
   - **Разрешить микрофон**;
   - **Спецвозможности** → CarVoice → включить (нужно для голосового ввода в других приложениях
     и запуска приложений по команде).
4. Нажмите **🎤 Проверить**.

## Запуск с шайбы Mercedes через Automate
В вашем flow замените блоки распознавания на один блок **App start**:
- Package: `com.carvoice.assistant`
- Activity class: `com.carvoice.assistant.AssistantActivity`

Или блок **Activity start** с Action `com.carvoice.assistant.LISTEN`.

Также на рабочем столе появится отдельная иконка **«Голос»** — она сразу запускает прослушивание.

## Модели
В настройках можно выбрать Claude Opus 5.5 (умнее), Sonnet 5.5 (быстрее) или Haiku 5.5 (самый быстрый и дешёвый).

## Сборка
APK собирается автоматически GitHub Actions при каждом push (`.github/workflows/build-apk.yml`).
