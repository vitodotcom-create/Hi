# Макеты экрана

- Только рисунок, код программы не трогать.
- HTML 1920×720 в scratchpad, рендер Playwright с `deviceScaleFactor: 2` (3840×1440) — высокое качество; для своей проверки уменьшить до 1920×720 jpg.
- Брать за основу последний одобренный макет (см. CLAUDE.md), менять только то, что попросили; все правки за один рендер.
- Стиль: спортивный AMG, тёмное стекло, рубленые углы, приглушённые цвета (не мешать при езде), без слова «Carlinkit».
- Учитывать: правый край экрана — мёртвая зона для нажатий; кнопки крупные.
- Отправить через SendUserFile и кратко перечислить, что изменилось.
