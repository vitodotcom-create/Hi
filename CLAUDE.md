# CarVoice — память проекта

## Бокс и машина
- Carlinkit AutoKit T-Box Plus (Android 13), Mercedes CLS 450 AMG 2019, Ереван. Язык общения — русский.
- Экран 1920×720 (8:3). Тачскрина нет: курсор шайбой/тачпадом.
- Панель в слоте «виджет навигации» Carlinkit: нажатия сдвинуты → калибровка (удержание 2 с). У правого края нажатия до панели не доходят — кнопки держать подальше от правого края.
- Play Защита блокирует установку (выключать сканирование на время). Спецвозможности: «Разрешить ограниченные настройки» (О приложении → ⋮) после первой попытки включить.
- Голос запускает Automate: шайба → App start `com.carvoice.assistant/.AssistantActivity`.

## Правила работы с пользователем
- Код НЕ трогать без команды. Сначала обсуждение/рисунок, код — только по просьбе.
- Собирать только по слову «собирай». Коммиты без сборки — с `[skip ci]`.
- После сборки всегда: ссылки на файлы и какой ставить (CarVoice / панель / оба), «поверх, без удаления».
- «делай стабильной» → `STABLE_VERSION` = тег, коммит с `[promote]` (сборки не будет).
- Правки — маленькими шагами, по одной новинке, каждую проверить в машине.
- Не писать слово «Carlinkit» в интерфейсе (кнопка: «СИСТЕМА · CARPLAY · ANDROID AUTO», в доке «МЕНЮ»).

## Рабочий стол (приложение `desktop/`, CarVoiceDesktop.apk)
- Отдельное приложение «Рабочий стол» на весь экран: WebView + `assets/desk/index.html` (дизайн) + `desk.js` (логика: кнопки → `Android.action(...)`, данные ← `cv.update(json)` раз в 2 с из DesktopActivity).
- Слева: боковая панель МЕНЮ (системный рабочий стол), РЕЖИМ (COMFORT/SPORT/RACE, запоминается), НЕДАВНИЕ, ЗВУК (своё окно громкости −/без звука/+), ТЕЛЕФОН; над ними часы и значки Wi-Fi/Bluetooth (+ имя сети). Окна ПОГОДА/СКОРОСТЬ/КУРС, 12 рубленых стеклянных плиток (Claude, Экран ½, Chrome, Wi-Fi, 70mai, Домой, Работа, WB, Gemini, Музыка, Радио, Настройки), красная кнопка «СИСТЕМА · CARPLAY · ANDROID AUTO».
- Центр: фон — видео-петля 1920×720 (чёрный CLS 2023, Panamericana), машина справа от плиток, перед в центре; плеер ⏮⏯⏭. Колесо и след фонарей убраны (всё есть в видео).
- Справа: часы, дата, CLS 450 AMG, последняя команда, погода, спидометр, карточка песни (нужен доступ к уведомлениям).
- Погода (Open-Meteo по адресу дома) меняет видео (`assets/desk/v_*.mp4`, 1920×720): дождь/гроза — `v_rain_night`/`v_rain_day`, ясно — `v_clear_night`/`v_sun` (солнце, витрины не горят), пасмурно/туман — `v_clear_night`/`v_cloudy_day`, снег — `v_snow_night`/`v_snow_day`. Поверх только туман и молнии. Скорость видео = GPS (стоим <5 км/ч или GPS молчит >4 с — пауза; скорость только от спутников (не от сети), 35 км/ч — ×1, 70 — ×2, макс ×2.5). На паузе поверх кладётся снимок кадра (canvas `#freeze`) и пустой poster — иначе бокс рисует серую заглушку с треугольником. Видео 60 к/с (ffmpeg minterpolate из 24, к концу добавлены 3 первых кадра — ровный стык). Размытия (backdrop-filter) поверх видео нет — бокс пропускал кадры. Видео пользователя (машина меньше и правее, вся улица в кадре) → петля: последняя 1 с плавно перетекает в первую → обрезка 180 px сверху и снизу без масштаба (scratchpad `full.sh`).
- Автозапуск: при включении бокса (BootReceiver, 7 с) и при пробуждении экрана; нужно «Поверх других приложений».
- Пользователь сам делает фото и видео (ИИ). Машина — чёрный CLS 2023 с решёткой Panamericana (вертикальные полосы) — так выбрал пользователь. Промпты пишет Claude, генерацию запускает пользователь сам.
- Проверка дизайна без сборки: Playwright-рендер `index.html` с заглушкой `window.Android` (scratchpad).

## Регистратор 70mai A810 (идея, в работе)
- Бокс берёт интернет с Wi-Fi телефона, SIM нет. A810 раздаёт Wi-Fi 2,4 ГГц (пароль по умолчанию 12345678), API: http://192.168.0.1/cgi-bin/*.cgi (разбор: alu.dog, reverse-engineering 70mai app).
- Бокс НЕ держит два Wi-Fi сразу. Интернет по Bluetooth с iPhone есть, но очень медленный — отказались.
- Тест v0.1.113: порты 80 и 554 открыты; RTSP отвечает 200 OK (/livestream/12 и др.) — видео брать можно; HTTP-команды .cgi рвут связь (нужна «привязка» как в приложении 70mai — отложено).
- Схема: бокс обычно на Wi-Fi iPhone. Плитка 70MAI → окно «● КАМЕРА / ОТКРЫТЬ 70MAI / ТЕСТ / ЗАКРЫТЬ». КАМЕРА = CameraActivity: ищет в списке сетей свою `70mai_A810_*` (рядом бывает чужая `70mai_A800S_5G_*` — из-за неё префикс-поиск висел и отменялся), WifiNetworkSpecifier по точному имени, WPA2, не вышло за 30 с — WPA3 (пароль 12345678) → bindProcessToNetwork → ExoPlayer media3 1.4.1 RTSP (каждый адрес TCP, потом UDP; при неудаче на экране список причин). v0.1.117: Wi-Fi подключается, DESCRIBE/SETUP проходят, но PLAY → 404 на всех адресах (TCP и UDP). Тест 5а (v0.1.118): DESCRIBE /livestream/12 → 200, Content-Base `rtsp://192.168.0.1/00000001/`, SDP a=control:* + H264 track1; SETUP …/00000001/track1 → 200 (TCP interleaved); PLAY на /livestream/12 → 404, PLAY на Content-Base → 200 и пошли RTP-данные. media3 1.4.1 (RtspClient) всегда шлёт PLAY по исходному uri, Content-Base игнорирует. Решение: `RtspPlayFix.kt` — посредник на 127.0.0.1 (плеер → посредник → регистратор через net.socketFactory, без bindProcessToNetwork), подставляет Content-Base в PLAY/PAUSE/TEARDOWN/GET_PARAMETER, видео идёт RTP поверх TCP. Проверено симуляцией (scratchpad `sim/`: fakecam.py = поддельный A810, exolike.py = клиент как media3, ffmpeg раскодировал 60 кадров 1280×720 через посредника); закрыли/ушли (onStop) → отпустить сеть, Android сам возвращается на iPhone. Сеть 70mai в настройках Wi-Fi бокса пользователь удаляет. На экране КАМЕРЫ кнопка «⇄ ЗАДНЯЯ/ПЕРЕДНЯЯ» (рядом с ЗАКРЫТЬ): передняя = /livestream/12, задняя = /livestream/11 (предположение). v0.1.121: КАМЕРА РАБОТАЕТ (передняя видна через посредника); «задняя» /livestream/11 показывала тоже переднюю. Тест 5б: на любой адрес DESCRIBE → 200, H264 848×480 (неизвестные адреса отдают переднюю). По проекту GitHub ClanSlum/Kino (просмотрщик A810): перед = /livestream/12, зад = /livestream/13 — теперь REAR=/livestream/13. Там же: HTTP .cgi у A810 требуют подписи (signkey md5, -source=wifi, токен после привязки client.cgi register), без неё обрыв — поэтому наши .cgi давали IOException.
- v0.1.114 (сборка из ветки claude/amazing-hypatia-94q1u8) = видео-стол + тест + КАМЕРА. Ветки claude/wizardly-fermi-aoqa9p и claude/amazing-hypatia-94q1u8 объединены — перед сборкой подтягивать обе.
